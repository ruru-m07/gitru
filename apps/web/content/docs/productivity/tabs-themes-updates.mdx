## Work with tabs

Tabs let you keep separate repository views open in one window. Create a tab with the plus button or <kbd>Command</kbd>/<kbd>Ctrl</kbd>+<kbd>T</kbd>.

- Select a tab to activate it.
- Drag tabs to reorder them.
- Middle-click a tab or use its close button to close it.
- Use <kbd>Command</kbd>/<kbd>Ctrl</kbd>+<kbd>Tab</kbd> to move forward and add <kbd>Shift</kbd> to move backward.

Gitru stores the tab and window state locally and restores it when the application reopens.

## Choose a theme

Open the Command Panel and choose **Switch Theme**. Gitru currently includes Gitru Dark, Gitru Light, Claude Dark, Claude Light, Caffeine Dark, Caffeine Light, Supabase, Vesper, and T3 Chat.

Text-diff layout and line-wrapping preferences are also remembered between sessions.

## Choose an update channel

Open the Command Panel and choose **Switch Update Channel**:

- **Stable** follows production releases and is the default for a fresh installation.
- **Beta** follows prereleases and receives features earlier.

Gitru checks again as soon as the channel changes. When an update is available, the sidebar shows an update action. Download and install it there; once installation finishes, the action changes to restart Gitru.

<Callout type="info" title="Current releases are beta">
  During the public beta, select the Beta channel to receive the current release train. A stable-channel installation will wait for a stable release.
</Callout>
