In this page, **Primary** means <kbd>Command</kbd> on macOS and <kbd>Ctrl</kbd> on Windows and Linux.

## Global shortcuts

| Action | Shortcut |
| --- | --- |
| Open the Command Panel | **Primary** + <kbd>K</kbd> |
| Create a tab | **Primary** + <kbd>T</kbd> |
| Close the active tab | **Primary** + <kbd>W</kbd> |
| Move to the next tab | **Primary** + <kbd>Tab</kbd> |
| Move to the previous tab | **Primary** + <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Close the window on macOS | <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> |

## Pickaxe results

| Action | Shortcut |
| --- | --- |
| Next match | **Primary** + <kbd>G</kbd>, or <kbd>Enter</kbd> while the query input is focused |
| Previous match | **Primary** + <kbd>Shift</kbd> + <kbd>G</kbd>, or <kbd>Shift</kbd> + <kbd>Enter</kbd> while the query input is focused |

## Keyboard navigation

Command Panel and focused list views use the arrow keys to move, <kbd>Enter</kbd> to open or select, and <kbd>Escape</kbd> to go back or clear the current selection.

<Callout type="info" title="About shortcut badges">
  Some Command Panel rows show proposed shortcut badges that are not wired as global shortcuts in the current beta. The tables above list only bindings implemented by the app.
</Callout>
