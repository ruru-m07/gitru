The Command Panel is the fastest route to actions that are not always visible in the current view.

Press <kbd>Command</kbd>+<kbd>K</kbd> on macOS or <kbd>Ctrl</kbd>+<kbd>K</kbd> on Windows and Linux. Start typing to filter by an action's name or related terms.

## Navigate the panel

- Use <kbd>Arrow Up</kbd> and <kbd>Arrow Down</kbd> to move through results.
- Press <kbd>Enter</kbd> to select an action.
- Press <kbd>Escape</kbd> to return to the previous panel or close it.

## Available workflows

The current repository and application state determine which actions can run. The panel provides entry points for:

- Creating, checking out, and rebasing branches
- Fetching, pulling, pushing, or publishing the current branch
- Switching, cloning, or initializing a repository
- Opening Pickaxe changed-content search
- Browsing stashed changes
- Switching the application theme
- Switching between stable and beta update channels

The labels shown beside some commands are discoverability hints in the current beta, not guaranteed global keyboard bindings. Use the verified bindings in [Keyboard shortcuts](/docs/productivity/keyboard-shortcuts).
