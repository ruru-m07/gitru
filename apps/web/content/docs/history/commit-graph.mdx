The graph view turns repository history into lanes. It is useful when you need to understand where a branch diverged, which commits have been merged, or which references point at a commit.

Open **History**, then switch to the graph view.

## What the graph shows

- Commit lanes and their parent relationships
- Local branch names
- Remote-tracking branch names
- Tags
- Stash references
- Commit subjects, authors, times, and change statistics

The activity panorama provides a compact view of the full loaded history while the main table stays readable. Scroll to explore older commits; Gitru loads more history as needed.

The graph is an overview rather than an editor. Use the regular history list to open a commit's changed files and detailed diff, and use the branch control for checkout, tracking, rename, or deletion actions.
