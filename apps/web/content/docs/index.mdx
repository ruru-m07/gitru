Gitru is a desktop Git client for reviewing local changes, creating commits,
following repository history, managing branches, syncing with remotes, and
working through rebases.

Gitru works with ordinary Git repositories. It uses the Git installation and
configuration already on your computer for most operations, so work done in
Gitru remains compatible with the command line and other Git tools.

## What is covered

These docs follow the **Local Git** area of the current `dev` branch. That is
where Gitru's complete repository workflow lives today:

- a repository picker for multiple local checkouts;
- staged, unstaged, conflicted, text, binary, and image changes;
- commits, commit details, a lane graph, and content history search;
- local and remote branch lifecycle management;
- fetch, pull, push, and first-time branch publishing;
- Gitru-managed stashes created while switching branches;
- plain, autostash, and interactive rebase flows.

Inbox and Issues are development-only previews. Pull Requests can appear in a
production build, but it is currently a placeholder rather than a complete
workflow. These areas are intentionally not documented as finished features.

## A good first path

1. [Install Gitru](./installation.mdx) and confirm `git` is available on your
   computer.
2. [Add, clone, or create a repository](./repository/add-clone-create.mdx).
3. Use the [interface tour](./repository/interface-tour.mdx) to find the branch,
   sync, changes, history, diff, and status areas.
4. Read [Working directory](./changes-diff/working-directory.mdx) and
   [Stage and commit](./changes-diff/stage-and-commit.mdx) before using a
   destructive action.

## Beta documentation

Gitru is currently distributed as a beta. These docs describe ongoing work on
the `dev` branch, so a published beta can trail a documented screen or action.
When that happens, check the app version in the lower-right status bar and the
[GitHub releases page](https://github.com/ruru-m07/gitru/releases).
